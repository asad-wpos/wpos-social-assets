# wpos-social-assets

Public image host for WPOS social posts scheduled through Buffer. Buffer's API attaches images by URL, so every
carousel slide and pin lives here and is linked as:

`https://raw.githubusercontent.com/asad-wpos/wpos-social-assets/main/<date-slug>/<file>.png`

One folder per post day: `slide-01.png` ... in swipe order (1080x1350), `pin.png` for Pinterest (1000x1500).
Only finished marketing images that are going public belong here. Source designs: `wpos-video-kit/src/scenes/`.
